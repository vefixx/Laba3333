```
Дана сигнатура метода: public int[] deleteNegative (int[] arr); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый 
массив, в котором записаны все элементы массива arr кроме отрицательных. 
 
Пример: 
arr=[1,2,-3,4,-2,2,-5] 
результат: [1,2,4,2]
```
### Алгоритм решения
1. Подсчитать количество отрицательных элементов в исходном массиве.
2. Создать новый массив длиной, уменьшенной на это количество.
3. Пройти по исходному массиву и скопировать в новый только те элементы, которые больше или равны нулю.
